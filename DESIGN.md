# Design notes

Written once so every screen stays consistent (and so AI helpers don't drift back to defaults).

**Direction.** A working document, not a landing page. Think analyst notebook: dense but calm,
text first, hairline rules instead of floating cards.

**Type.** Newsreader (serif) for account names and section titles, regular weight, never italic
for decoration. Public Sans for UI and body. IBM Plex Mono only for numbers, IDs and file content.
Sentence case everywhere, no all-caps headings.

**Color.** Neutral paper background, near-black ink, one accent (cobalt `#2340D8`) for
interactive elements and the top priority mark. Status colors only for account health, always
paired with a word. No gradients, glows or colored shadows.

**Layout.** Left rail with the account list, main column left-aligned. Sections separated by
1px rules and whitespace. Corner radius 3px max. No icon-on-top feature cards, no stat banners,
no badges above headings.

**Copy.** Plain and specific. "Send brief to Slack", not "Supercharge your workflow".
