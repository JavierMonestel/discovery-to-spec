# Prioritization rubric

Score every gap on two axes. Priority = impact x (6 - effort), so high impact and low effort wins.

## Impact (1 to 5)

| Score | Meaning |
|---|---|
| 5 | Customer attaches a clear cost (hours, money, churned clients, compliance risk) AND says it is urgent |
| 4 | Clear cost OR repeated several times by more than one stakeholder |
| 3 | Real pain for one team, mentioned with some detail |
| 2 | Annoyance, workaround exists and is tolerable |
| 1 | Nice to have, mentioned in passing |

## Effort (1 to 5)

| Score | Meaning |
|---|---|
| 1 | A single AI skill or prompt workflow, inputs already available, no integrations |
| 2 | Skill plus one simple integration (webhook, spreadsheet, email) |
| 3 | Needs data from two or more systems or an approval step |
| 4 | Needs custom integration with a system that has a weak or no API, or cleanup of messy data |
| 5 | Needs process change across teams, new data collection, or regulated data handling |

## Categories

Use one of: `reporting`, `content`, `support`, `operations`, `analytics`, `data-quality`, `enablement`.
